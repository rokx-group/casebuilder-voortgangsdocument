// IN HET VELD

Waar deze modellen terechtkomen

Je weet wat je vervoert, niet hoe een flightcase heet. Dit is wat er bij anderen in ging, en welk model dat werd.

Moving heads op tour // Trunccase · op wielen

Vier armaturen in één kist met vakverdeling. Tien keer per jaar de vrachtwagen in en uit.
Drone, accu's en controller // Koffer · uitgefreesd schuim

Elk onderdeel in een eigen uitsparing, ook de propellers. Open de koffer en je vliegt.
Meetopstelling het terrein op // Trunccase · in eigen kleur

Draagpunten op de behuizing, nooit op het display. Zeven kleuren, dus je ziet van ver wiens kist het is.
19-inch tussen twee locaties // Rackcase dubbel · bekabeling achterin

Voor- én achterdeksel, want de kabels zitten achter. Aansluiten zonder de kist te draaien.
