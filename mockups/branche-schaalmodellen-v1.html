Waar het hier om draait

Vier dingen bij een onvervangbaar model

Hier is er geen tweede exemplaar. Dat verandert elke afweging: liever te veel schuim dan één keer te weinig.

// 01Dragen op het onderstel

Een maquette dragen op de opbouw breekt de opbouw. Het schuim pakt de plaat eronder, niet het gebouw erop.

// 02Uitnemen zonder kantelen

Wat je alleen scheef uit de kist krijgt, valt een keer. Dus deksel er helemaal af, en tilbanden onder het model.

// 03Zacht waar het uitsteekt

Torens, masten en luifels krijgen een eigen uitsparing in zachter schuim dan de rest.

// 04De kist is ook de tafel

Op de beurs staat het model vaak op de omgekeerde kist. Dan moet de bodem vlak zijn en de buitenkant toonbaar.

Hoe we het maken

Wat we doen bij één exemplaar

Bij maatwerk van één stuk is de eerste keer ook de laatste keer. Daarom zit het werk vooraf.

// 01Opmeten bij jou

Voor modellen die niet vervoerd kunnen worden zonder kist komen we meten. Anders is het een kip-eiprobleem.

// 02Passen voor het dicht gaat

Het model gaat één keer in de kist bij ons, of anders bij jou met de kist erheen.

// 03Retourverpakking meegeleverd

Een kist die heen wél en terug niet dichtgaat, is een half product. Instructie ligt in het deksel.
