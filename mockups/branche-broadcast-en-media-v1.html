Waar het hier om draait

Vier dingen die op locatie tellen

Een broadcastcase gaat vaker open dan dicht. Wat hieronder staat bepaalt hoe snel er gedraaid kan worden.

// 01Werken uit de kist

Bij een regiekoffer blijft alles ingebouwd: deksel eraf, aansluiten, draaien. Uitpakken kost tijd die er niet is.

// 02Kabels apart

BNC, glasvezel en stroom in een eigen vak. Los tussen de camera's schuurt de connectoren stuk.

// 03Wielen die remmen

Een studiovloer loopt af naar de put. Zonder rem staat de kist niet waar je hem zet.

// 04Gewicht per kist

Vliegvracht rekent per kilo en per stuk. Twee kisten van 30 kg zijn goedkoper dan één van 60.

Hoe we het maken

Waarom deze cases het langer volhouden

Broadcastcases gaan tien keer per jaar de bus in en uit, jarenlang. Dat is minder een ontwerpvraag dan een slijtagevraag.

// 01Beslag dat je kunt vervangen

Popnagels, geen lijm. Een kapotte sluiting is een onderdeel van € 12, geen nieuwe kist.

// 02Hoeken op de slijtpunten

Balhoeken waar hij neergezet wordt, overzethoeken waar hij langs de laadklep schuurt.

// 03Zelfde kist, jaren later

De tekening blijft bij je ordernummer. Een tweede set past in dezelfde stapel.
