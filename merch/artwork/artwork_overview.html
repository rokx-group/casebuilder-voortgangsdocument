CaseBuilder merch · print artwork

Vector artwork for concept 1. All text is converted to outlines, every file is at real size (mm). Folders are named product_printer. Each piece has a _print file (transparent, white = white ink, send this to the printer) and a _preview PDF on the garment colour (for review only). Logos come from the official CaseBuilder vector files; fonts are the brand fonts Barlow Condensed and IBM Plex Mono.
